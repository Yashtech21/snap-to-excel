Snap to Excel

Capture screenshots into a local Excel workbook or a OneDrive/SharePoint workbook.

Destination type

Excel workbook on this device

Choose an existing .xlsx file. Screenshots are embedded in the workbook and metadata is added as a new row. The file stays on this device.

No workbook selected

Each capture adds to the “Screenshots” worksheet. Keep the workbook closed in Excel while capturing. Use a simple workbook dedicated to screenshots; advanced Excel features may not be preserved when the file is rewritten.
